# Memo Alive 微信小程序

这是现有 Memo Alive 本地后端的原生微信小程序客户端。它不会替换或迁移现有的 PostgreSQL 数据库和原始音频。

## 1. 先启动后端

在项目根目录只启动 PostgreSQL 和 API：

```bash
cd "<PROJECT_ROOT>"
docker compose up --build postgres api
```

待容器启动后，可在浏览器或终端确认 `http://127.0.0.1:8000/health` 返回正常。不要运行 `docker compose down -v`；`-v` 会删除 PostgreSQL 数据卷。

## 2. 导入微信开发者工具

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择 `<PROJECT_ROOT>/wechat-miniprogram`，不要选里面的 `miniprogram/` 子目录。
3. 本地演示可使用配置中的测试 AppID `touristappid`。
4. 编译后，默认连接 `http://127.0.0.1:8000`。

## 3. Mock 演示流程

没有配置 `DASHSCOPE_API_KEY` 时，后端默认进入 Mock 演示模式：

1. 进入“录制”，允许麦克风权限，录一段音频后停止并试听。
2. 点击“上传并整理”。原始音频会先真实保存，Mock 内容不会冒充语音识别结果。
3. 选择“使用内置示例转写”，或手动输入这段音频的真实转写。
4. 等待整理完成，检查标题、整理稿、原始音频和只读原始转写。
5. 再录一条相关内容，可在“待审批”选择新旧内容，并在“时间线”查看变化。

## 4. 修改后端地址

在“备忘录”页点击右上角“后端”，输入完整的 `http://` 或 `https://` 地址并保存。地址会保存在小程序本地存储中；填写时不要带 `/api/v1` 后缀。如需恢复本机模拟器默认值，设为：

```text
http://127.0.0.1:8000
```

## 5. 开发者工具与真机的网络区别

- **开发者工具**：本项目已将本地域名校验关闭，可用 `http://127.0.0.1:8000` 连接电脑上的 API。如工具仍阻止请求，在“详情 → 本地设置”勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。
- **真机**：手机里的 `127.0.0.1` 指向手机自身，不是开发电脑。真机调试或发布时，后端必须是手机可访问的 **HTTPS** 地址，证书有效，并在微信小程序后台配置 request/uploadFile/downloadFile 合法域名。

## 6. 数据边界

小程序只是新客户端，不会将数据复制到微信，也不会自动迁移数据。现有 PostgreSQL 数据仍在 Docker volume，原始音频仍在项目根目录的 `data/audio/`。更换后端地址只是切换连接目标，不会携带或合并原有数据。
